# Students and enrollment

Use **People → Students**. Select the campus and academic cycle first.
You need student read or management permission for the operation.

## Enroll a learner

1. Create or select the person's account.
2. Enter the admission number and admission date.
3. Select the academic level and section for the cycle.
4. Save the enrollment.
5. Review the account, placement, and status in the student record.
6. Link guardians and issue invitations when family access is required.

An account represents the person. The student record represents enrollment.
Dated placements retain class and section history.
Do not create another person to change their placement.
An admission number must be available in the destination campus.
An active learner cannot be made staff. A learner enrolled elsewhere needs a campus move or transfer.

## Change placement or status

Select a level and section belonging to the same campus and cycle.
Capacity checks include seats reserved by admission offers.
The application keeps the previous placement in its history.
Use today's date or an earlier valid date. Future enrollment changes are not accepted.

| Status | Meaning |
| --- | --- |
| Active | The learner attends and can receive new operational records. |
| Suspended | Enrollment remains, but the learner is not attending. |
| Withdrawn | The learner has left the enrollment. |
| Transferred | The learner has moved through a transfer workflow. |
| Graduated | The learner has finished through graduation. |
| Archived | The enrollment is retained outside normal use. |

Only Active learners count as attending.
Reinstatement checks current enrollment elsewhere, staff status, and destination capacity.
Closed enrollment states cannot receive a normal new placement.
