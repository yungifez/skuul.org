# Boarding houses, rolls, and nights away

Enable Boarding before using **Boarding → Houses** or **Nights away**.
Select the campus, cycle, and period where required.
You need boarding permissions for the operation.

## Prepare boarding places

1. Create the boarding house.
2. Add rooms and beds.
3. Set each room's availability.
4. Assign eligible campus staff as supervisors.
5. Select an eligible learner and available bed.
6. Save the placement and check the occupancy list.

An occupied or unavailable bed cannot receive another learner.
The bed and enrollment must be valid for the campus.
Room and house closure checks prevent leaving current boarders in unavailable places.
Ending or moving a placement keeps its history.
A campus move or departure releases the learner's bed.
Suspension does not automatically release it.

## Use an organization residence

Create the shared residence through the organization boarding-residence page.
Link its campuses, then attach their houses.
All links must belong to the same organization and residence.
A campus cannot be unlinked while houses still depend on that link.
Shared residence configuration does not grant unrestricted access to other campuses.

Open the house's boarding roll workflow.
Select the date and roll type, then start the roll for its boarders.
Record each learner's state and review missing entries.
Complete the roll only when all required entries are recorded.
A completed roll is read-only.

## Process nights away

Select a current boarder and enter the departure and return dates.
Dates cannot overlap another applicable leave request.
Review the request, then approve or refuse it with the required authority.
States are Requested, Approved, Refused, Cancelled, and Returned.
Record the learner's return through the leave workflow.
Ending boarding can cancel leave that has not begun.

Families see eligible placements and leave through the Boarding portal area.
## Check the result

- Check bed occupancy and placement history.
- Confirm the completed roll has no required unrecorded entries.
- Check the decision and return state of a nights-away request.
