# Teacher

The `teacher` role supports teaching preparation, attendance, and working marks.
An offering assignment identifies the classes or subjects you teach.
The role alone does not create that assignment.

## Before your first lesson

1. Accept your invitation and complete the required sign-in steps.
2. In the working bar, select the **Working academic year** and **Working term**.
3. Ask the campus administrator to confirm your offering and section assignments.
4. Open **Assessment → Gradebooks** and find the intended offering.
5. Review the published timetable, syllabus, and learner roster.

The default sidebar shows these entries:

| Group | Entries |
| --- | --- |
| People | **Students** |
| Teaching | **Syllabi**, **Timetables**, **Attendance** |
| Assessment | **Gradebooks**, **Exam schedules** |
| Operations | **Calendar**, **Notices** |

The template includes `read gradebook`, `manage gradebook`, `read attendance`, and `take attendance`.
It also includes syllabus and ordinary timetable permissions, `read exam`, and `read ranking`.
Gradebook access checks an assignment or `update subject` in addition to the gradebook permission.
A previous teaching assignment permits reading; changing marks requires an assignment that has not ended.
The teacher template does not include `update subject` or `read subject`.

## Record daily attendance

1. Open **Teaching → Attendance**, or select **Take attendance** on the dashboard. The [attendance register](../academics/attendance) opens.
2. Select the **Section**. The **Day** is today by default.
3. Use **Previous day**, **Today**, or **Next day** to change the day.
4. Check the learner list.
5. Select each learner's attendance state.
6. Select **Save register**. The message "Attendance register saved." appears.
7. Reload the same section and day, and check the saved states.

The states are Present, Absent, Late, Excused, Left early, Remote, School activity, and Not recorded.
Use **Mark everybody present** or **Mark everybody absent** only after you check the exceptions.
Excused remains in the attendance-rate denominator.
The register records daily section attendance. It has no lesson-register selector.
The **Section** list shows every section in the working year, not only your assigned sections.
Follow campus policy when you read or record learners outside your assigned teaching work.

## Prepare syllabi and lesson notes

Open **Teaching → Syllabi**.
Use [syllabus instructions](../academics/syllabi) to create an offering's draft with **Add syllabus** and add topics.
Select **Send for review** when the outline is ready.
A reviewer publishes it or returns it for changes.
From a published syllabus, open **Lesson notes**, prepare the weekly draft, and send it for review.
Record coverage for the assigned section as Covered, Partial, or Skipped.
An assignment without a section covers the offering; section-specific assignments limit coverage accordingly.
The teacher template does not grant `approve syllabus`.

## Enter and correct marks

1. Open **Assessment → Gradebooks** and select **Open gradebook** for the offering.
2. Under **Marks**, select the **Assessment**.
3. For each learner, select the entry state and enter the mark or scale option.
4. Select **Save marks**.
5. Review the saved counts and row errors.
6. Reload the sheet and check the calculation under **Results**.

The entry states are Graded, Missing, Absent, Exempt, Incomplete, and Not applicable.
Missing, Absent, and Incomplete numeric work counts as zero. Unentered work also counts as zero.
Exempt and Not applicable work is excluded.
Use **Put back** to discard unsaved edits before you change the assessment.
Review a concurrent-edit warning before you select **Save marks** again to replace another person's value.
Use **Add assessment** to add an assessment to an open gradebook.

## Submit results when delegated

The teacher template does not include `publish result` or `approve result`.
Ask the campus administrator whether result submission is part of your delegated duties.
With `publish result` and eligible offering access, save and review the marks first.
Then, under **Results**, open the learner's more menu and select **Send for approval**.
A different authorized reviewer must approve the revision.
For a correction, save the changed marks and select **Send a new revision** from the same menu.
Follow [result approval](../academics/results). Working marks alone do not change the family's official result.

## Other teaching and staff tasks

Use [timetable instructions](../academics/timetables) for permitted drafts, revisions, and cover.
School-wide timetable creation requires an additional permission beyond the teacher template.
Read [exam schedules](../academics/exams) under **Assessment → Exam schedules**. Exam creation and editing are not part of the teacher template.
Read eligible notices and calendar events under **Operations**.
The leave board requires separately delegated `read staff leave` and `request staff leave`.
Follow [staff responsibilities](./delegated-staff#staff-employment-and-leave) when that access is assigned.

| Problem | Action |
| --- | --- |
| Gradebook is absent or read-only | Check offering assignment, campus, period, and assignment end date. |
| Result submission control is absent | Ask the administrator to review `publish result`. |
| Syllabus cannot be approved | Send it to the authorized academic reviewer. |
| Mark save reports some row errors | Review saved counts; correct failed rows without assuming every row failed. |
| Family still sees an earlier result | Check approval of the new revision. |

Use [daily checks](./daily-checks#complete-teaching-records) and [academic handover](../academics/year-end#finish-and-approve-academic-work) for record review.
