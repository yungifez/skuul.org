# Use the workspace

Sign in with the email address attached to your account. There is no public registration.
Use the invitation from your administrator to set your first password.

## Choose the working context

![The dashboard for Riverside High School shows the working year and semester, setup progress, attendance today, the next seven days, and trends.](/images/current/workspace-light-desktop.webp)

The working bar names the school year and term that every screen uses.

1. Open the dashboard.
2. Select the campus where you need to work.
3. Select the academic cycle.
4. Select the teaching period when the page requires one.
5. Check these selections before entering records.

The campus selector lists campuses where you have access. An organization role does not automatically grant campus access.
Lists and actions use the selected campus. Many teaching pages also require a cycle and period.
Finance uses financial periods separately from teaching periods.

Campus labels can differ. For example, a campus can show **Grade** instead of **Class**, or **Semester** instead of **Term**.
The guides use academic level, section, cycle, and period where a label can vary.

## Find a page

The sidebar groups pages under Organization, Setup, People, Teaching, Assessment, Operations, Staff, Finance, Boarding, Facilities, Library, and Imports.
The command menu uses the same permitted destinations.
A missing menu entry can mean that a feature is disabled or that your role lacks permission.
Changing the address does not grant access.

**Everything of mine** opens the family portal. **Notification settings** controls notice email preferences.
**School calendar** opens the calendar view available to your account.

## Save and review changes

Wait for the save result before leaving a form. Read validation messages beside each field.
Some forms detect changes made by another person. Review the current value before confirming an overwrite.
A closed period, archived record, or published revision can prevent editing.
Use the workflow for correction or revision instead of creating a duplicate.

## Return to an earlier record safely

Select the record's owning campus before correcting historical records.
For academic records, also select its cycle and period.
A learner's later campus or placement does not change ownership of earlier attendance or ledger entries.
Open the existing record rather than creating a replacement identity.
Read its publication or closure state before selecting an edit action.
For published academic records, follow the revision and approval procedure.
For posted finance records, follow the correction or reversal procedure.

If a save fails, preserve the displayed error and record identifier.
Reload to confirm whether any part of the operation succeeded before submitting another request.
Gradebook rows and import rows can succeed separately.
Do not treat a timeout as proof that nothing changed.

Start with the [worked campus exercise](../getting-started/first-campus) when learning the normal task sequence.

| Problem | Action |
| --- | --- |
| Historical record is missing | Select its owning campus, cycle, and period. |
| Edit control is absent | Check permission, record state, and publication or closure. |
| Save times out | Reload the record and verify what succeeded before retrying. |

## Check the result

- Confirm the intended campus appears in the workspace.
- Confirm the selected cycle and period match the records you will change.
