# Application terms

| Term | Meaning |
| --- | --- |
| Organization | The body that owns one or more campuses. |
| Campus / school | The boundary for operational records and campus permissions. |
| Working campus | The campus selected for staff work. |
| Account / person | A person's sign-in identity and common profile. |
| Campus membership | A person's access relationship with one campus. |
| Enrollment | A learner's student record and enrollment status. |
| Placement | The learner's level and section for a cycle, with dated history. |
| Academic cycle / year | The dated teaching year or equivalent cycle. |
| Academic period | A term, semester, or other dated part of a cycle. |
| Academic level | A reusable class, grade, or level in the campus structure. |
| Section | A class group attached to a level and cycle. |
| Subject | A subject in the campus catalogue. |
| Course offering | A subject taught to a defined roster during a cycle or period. |
| Teaching assignment | A teacher's responsibility for a course offering. |
| Gradebook | Assessment categories, items, and entries for an offering. |
| Result snapshot | A saved result revision that requires approval before family publication. |
| Cohort / group | A named group of people separate from class placement. |
| Programme | A club, intervention, or other service with participation records. |
| Financial period | A period that controls posting to the ledger. |
| Ledger | The balanced accounting record of posted transactions. |
| Unapplied credit | Money held for a learner that has not settled an invoice. |
| Billing group | Campuses that permit balance carry during a campus move. |
| Feature profile | Campus switches that enable optional application areas. |
| Audit record | The actor, event, time, and recorded details of a change. |

A role is a permission bundle. A role name alone does not prove access to a particular campus or record.
See [roles and permissions](../administration/permissions).
