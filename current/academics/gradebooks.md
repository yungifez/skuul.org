# Gradebooks and grading scales

Use **Assessment → Gradebooks** for an active course offering.
You need gradebook permission and access to the offering.
The offering's roster defines the learners in the gradebook.

## Build the assessment structure

1. Create the assessment categories.
2. Select the aggregation rule and category weight where required.
3. Add assessment items and their dates.
4. For numeric items, set a positive maximum mark.
5. For scale items, select the active grading scale.
6. Review the structure before entering marks.

Comment-only items record text and do not affect point totals.

Aggregation choices include weighted mean, simple mean, highest, and sum.
Use the rule that matches the campus assessment policy.
Save a structure as a template when it will be reused.
Apply a template only to an empty gradebook structure.
Templates copy assessment structure, not learner grades.

Enter a numeric mark between zero and the item's maximum, or choose a valid scale option.
Record the entry state explicitly when a normal mark is unavailable.

| Entry state | Effect on numeric calculation |
| --- | --- |
| Graded | Uses the entered value. |
| Missing, Absent, Incomplete | Contributes zero. |
| Exempt, Not applicable | Excluded from the calculation. |

An unentered numeric item also contributes zero in the current calculator.
Review missing entries before publication and closure.
A calculated zero is not proof that a teacher deliberately awarded zero.
Save pending marks before changing the assessment structure.
If another person changed a mark, review the warning before confirming an overwrite.

## Manage scales

Scale types include descriptive, percentage, GPA, and points.
Create at least two uniquely named options.
Numeric scales need valid numeric values within their maximum.
Descriptive options have no numeric value.
A scale already used in records has restrictions on changing its type, maximum, and used options.
Retire it and create a replacement when the grading policy changes.

## Check the result

- Reload the marksheet and confirm the saved values and states.
- Review calculated totals and excluded items.
- Check unentered and incomplete items before submission.

See [result approval](./results) for publication and [calendar closure](./calendars) for incomplete-work checks.
