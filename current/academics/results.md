# Result approval and official documents

Working marks, approved results, report cards, and transcripts are separate records.
Saving marks does not publish them to families.
Submitting a result saves a revision; approving it makes that revision official.

## Before you start

Use `read gradebook` to open the offering's gradebook.
Use `publish result` to submit results and `approve result` to review them.
Gradebook access also checks [teaching assignments](./gradebooks#access-and-prerequisites).
A reviewer needs access to the gradebook as well as approval authority.
Report-card and transcript directories require `read report`.
Issuing these documents requires `create report`.

## Submit one learner's result

1. Open the offering's gradebook.
2. Save all intended marks using **Save marks**.
3. Review excluded, missing, absent, incomplete, and unentered items.
4. Find the learner's result controls.
5. Select **Send for approval**.
6. Confirm that a numbered revision is waiting for approval.

The submission captures the calculation and assessment data at that time.
Later mark changes do not change this saved revision.
An identical waiting revision cannot be submitted twice.
The operation applies to the selected learner, rather than approving the whole marksheet.

## Approve or return a result

1. Sign in as a different authorized reviewer.
2. Open the offering's gradebook and find the waiting revision.
3. Check the learner, marks, entry states, and calculated result.
4. Select **Approve** when the revision is correct.
5. Confirm the approved revision number and date.

To return a revision, select **Send back**.
Enter what the teacher must change, using up to 500 characters.
Confirm **Send back**. The marksheet shows the returned reason.
The submitter cannot approve their own revision.
A newer revision prevents approval of an older revision.

## Correct an official result

1. Correct the affected marks and select **Save marks**.
2. Select **Send a new revision** for that learner.
3. Ask a different reviewer to check and approve the new revision.
4. Verify the new approved revision in the family portal.

The previous snapshot remains stored.
A pending or returned correction does not replace the family's latest approved result.
For example, revision 1 stays visible while revision 2 waits for approval.
After approval, families read revision 2.
Previously issued report cards and transcripts remain fixed; reissue them separately.

## Publish a report card

1. Open the report-card directory.
2. In **Publish a report card**, select **Learner**.
3. Select the academic period.
4. Enter **Reason for a revision** when reissuing a card.
5. Select **Publish**.
6. Open the resulting card and check its learner, period, and revision.

The learner and period must belong to the working campus.
The period must be Closing, Closed, or Archived.
At least one approved subject result is required.
An Open period is not ready for this document workflow.
Publishing again creates a new fixed revision.
Use the directory's learner, cycle, and period filters to find older cards.

## Issue a transcript

1. Open the transcript directory.
2. In **Issue a transcript**, select **Learner**.
3. Enter **Reason for a revision** when reissuing a transcript.
4. Select **Issue transcript**.
5. Open the issued revision and review its published subject history.

A transcript requires at least one approved result.
It records the available published history at issuance.
Later approvals require a new transcript revision to update that issued document.
Families need the Documents portal area enabled to read eligible issued documents.

## Resolve publication problems

| Problem | Action |
| --- | --- |
| Submission controls are absent | Check `publish result`, current teacher assignment, and period status. |
| Approval is refused | Use another reviewer and select the latest waiting revision. |
| Calculation differs from expectations | Review category weights, item weights, and entry states in the gradebook guide. |
| Family sees the older result | Check whether the new revision is approved. |
| Report card cannot publish | Close or begin closing the period, then check for approved subject results. |
| Issued document still contains an old mark | Reissue the document after the corrected result is approved. |

## Compare results

Enable Ranking and open **Assessment → Rankings**.
Filter by cycle, period, level, section, cohort, or subject as required.
**Whole group** includes levels inside the selected level group.
Check those filters before comparing learners with different assessment sets.

Generic [report exports](../operations/reports) are separate from issuing official document revisions.
